# RAVIN QC Audit — نظام تقييم زيارات الجودة

تطبيق ويب واحد (PWA) شغال بالكامل من المتصفح، من غير أي سيرفر أو قاعدة بيانات — كل بيانات الزيارة بتتخزن على جهاز المستخدم نفسه (localStorage).

## محتويات المجلد

```
index.html          ← التطبيق نفسه (كل الكود جوه ملف واحد)
manifest.json        ← بيانات التطبيق (الاسم، الأيقونة، الألوان) عشان يتثبّت كـ"تطبيق"
service-worker.js     ← بيخلي التطبيق يفتح حتى من غير إنترنت بعد أول مرة
icons/                ← أيقونة RAVIN بمقاسات مختلفة
```

## الخطوة 1 — رفعه على GitHub

1. اعمل Repository جديد على GitHub (public أو private، الاتنين يشتغلوا).
2. ارفع محتويات المجلد ده كله (بما فيه مجلد `icons`) في الـ Repository، من غير ما تغيّر أسماء الملفات أو أماكنها.
   - أسهل طريقة: من صفحة الـ Repo اضغط **Add file → Upload files**، واسحب كل الملفات والمجلد مرة واحدة.
3. اعمل Commit.

## الخطوة 2 — تشغيله كموقع (GitHub Pages)

1. من الـ Repo: **Settings → Pages**.
2. تحت **Branch** اختار `main` والمجلد `/ (root)`، واحفظ.
3. بعد دقيقة أو اتنين هيديك لينك زي:
   `https://<username>.github.io/<repo-name>/`
4. افتح اللينك ده — ده نسخة التطبيق الشغالة أونلاين.

## الخطوة 3 — تحويله لتطبيق فعلي على الموبايل

في طريقتين:

### أ) تثبيت مباشر (الأسرع، بدون أي خطوات إضافية)

افتح لينك GitHub Pages من موبايل الأندرويد أو الآيفون، وبعدين:
- **أندرويد (Chrome):** هيظهرلك تلقائي خيار "Add to Home Screen" أو من قائمة التلات نقط اختار **Install app**.
- **آيفون (Safari):** من زرار المشاركة (Share) اختار **Add to Home Screen**.

التطبيق هيتثبت بأيقونة RAVIN على الشاشة الرئيسية، ويفتح بملء الشاشة زي أي تطبيق عادي، ويشتغل حتى من غير إنترنت بعد أول فتح.

### ب) تطبيق حقيقي (APK / متجر التطبيقات)

لو عايز ملف APK لأندرويد أو تطبيق لمتجر آبل:

1. روح على [pwabuilder.com](https://www.pwabuilder.com)
2. حط لينك GitHub Pages بتاعك.
3. اختار **Android** أو **iOS**، وهو هيبني الباكدج جاهز للتحميل أو للرفع على المتجر.

## ملاحظات مهمة

- البيانات (الزيارات، الجرد، الصور...) متخزنة في متصفح/جهاز المستخدم بس (localStorage) — مفيش مزامنة بين الأجهزة تلقائياً. لو عايز مزامنة حقيقية بين فروع/أجهزة مختلفة، ده محتاج Backend وقاعدة بيانات (خارج نطاق الملف ده).
- لو غيّرت أي حاجة في `index.html` مستقبلاً، ارفعها تاني بنفس الاسم على GitHub وهيتحدّث اللينك تلقائي.
- الخط (Cairo) ومكتبة قراءة ملفات الإكسل (SheetJS) بيتحمّلوا من الإنترنت أول مرة بس، وبعد كده بيتخزنوا في الكاش.
